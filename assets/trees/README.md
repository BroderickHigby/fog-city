# Detailed showcase trees

The high-tier tree generator is `@dgreenheck/ez-tree` 1.1.0 by Daniel Greenheck, published January 15, 2026. Source: https://github.com/dgreenheck/ez-tree. The package and bundled bark/leaf textures are distributed under its MIT licence; the full notice ships at `public/models/ez-tree-license.txt`. No external texture request is needed at runtime.

The generator creates three seeded prototypes. Near instances replace the original trees only while actually drawn. Originals remain during load/failure, beyond the detailed-instance limit, and outside the showcase. All changes are render-only.
