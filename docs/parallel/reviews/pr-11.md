**What holds up:**

- **Crisis check:** runs on the raw text before anything else.

1. **high**, `src/ui/navigation.ts:13-17`, called from `minimap.ts:18` on every HUD update (checked)
   - **Problem:** Dijkstra re-sorts every pending node on each step and filters every edge.
   - **Failure:** the SF road graph has 9,441 nodes and 15,671 edges, so with a waypoint set every HUD update runs about 10⁹ operations and the game freezes.
   - **Fix:** build an adjacency index, use heap-based A*, and cache the route per (start node, waypoint).
2. **high:** the roadmap's "no raw text input outside FreeTextBox" lint is missing.
   - **Fix:** add `tests/ui/no-raw-inputs.test.ts`, which scans `src/**` and `index.html` for `<input`, `<textarea`, `createElement("input"|"textarea")` and `contenteditable`. Add a crisis-phrase test for every `TEXT_BOXES` id; only `startup` has one today.
3. **medium:** `tests/ui/browser.spec.ts` and `browser.config.ts` never run.
   - **Problem:** Vitest only picks up `*.test.ts`, and Playwright's `testDir` is `tests/e2e`.
   - **Fix:** ask Lane 2 to add them as a Playwright project.
4. **medium**, `src/ui/free-text.ts:19-20` (checked)
