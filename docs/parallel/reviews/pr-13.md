**Wave 3 (this PR)**
1. **medium**, `attacks.ts:168` with `effects.ts:60, 124-130` (checked)
   - **Problem:** rain and fog rust set `lastWaterTick` every tick, and the phone hack treats any water after it starts as an interrupt.
   - **Failure:** any rain, or a foggy night, cancels every phone hack one tick after it starts.
   - **Fix:** track direct water separately, for example `lastDirectWaterTick`.
2. **medium**, `effects.ts:125` and `perception.ts:8`
   - **Problem:** fog rust and sight range read one global `ctx.fog`.
   - **Failure:** dense fog in the Sunset rusts and blinds robots in SoMa.
   - **Fix:** a fog value per actor, or a `fogAt(x, z)` callback.
3. **low:** rain and King-tide puddle refills exist only on the consuming side; nothing ties them to rain.
