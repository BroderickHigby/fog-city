# Campaign / high-detail captures

Actual Chromium screenshots of the packed SF build, not generated concept art. 1920 × 1080 viewport, pixel ratio 1, `gfx=high`, golden-hour preset. Software WebGL on this build machine: these images establish rendered appearance, not hardware frame rate.

- `ferry-material-detail-1920.png`: close view of the current Ferry asset, showing sandstone/paving detail and the campaign interface. This view is not the owner's earlier camera position.
- `ferry-golden-1920.png`: plaza view from local x=-115, z=130, yaw=40°, pitch=7°, camera height 2.2 m above the ground; final packed-build capture after fixing the canopy distribution.

The close view still exposes simple windows/awnings and the broader game still needs a dedicated asset/detail pass. The new foliage is procedural leaf-card geometry; existing scanned ground materials retain their original licence records in `assets/textures/README.md`.
