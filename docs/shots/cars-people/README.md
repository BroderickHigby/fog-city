# Car artwork and running feet

- [Car artwork](car-wraps.png): original paint-only graphics on the actual civilian-car model. Glass, lights and tyres retain their materials. This diagnostic capture uses software WebGL; its FPS overlay is not a hardware performance measurement.
- [Running feet](running-feet.png): the same player model, motion phases and cameras before and after correction. The worst planted right-toe yaw changes from 35.4 degrees during jogging and 20 degrees during sprinting to 8 degrees. The lower row shows the player and crowd models on 20 percent uphill/downhill test surfaces.

The [acceptance cases](../../qa/cars-and-people.md) describe the playable behavior and verification requirements. These images are visual evidence, not certification of the complete game or a public deployment.
