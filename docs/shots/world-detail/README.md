# World detail screenshots

Software-rendered (SwiftShader, 1280x720, scaled) captures from `?world=sf` through
`window.__fogcity.flyTo`, the HUD hidden. Left: `integrate/wave2` (`ff7db5b`), the same build
with the street-detail layers removed. Right: with them. These are behaviour evidence, not a
hardware look or performance claim.
